📖 Method & Sources (verified 2026-10-21)

How a pick is generated (in order)

  1. Fixture list only from Hotspawn: play.hotspawn.com/lol-pickems — teams, tournament, start, tier/points, match URL. Picks lock 5 min before start per play.hotspawn.com/how-it-works. Hotspawn crowd % is context only, never a probability input.
  2. 💰 Esportsbook lines: OddsPapi (LoL sportId 18, Winner market 181; network incl. Pinnacle/bet365; docs: oddspapi.io/sports/esports/lol) when the free ODDSPAPI_KEY secret is set. Decimal odds de-vigged: p=(1/odds)/Σ(1/odds), median across books.
  3. 💰 Prediction market: Polymarket public Gamma API gamma-api.polymarket.com (LoL-tagged events), outcome prices used directly.
  4. 🧮 Our own line (fallback for low-tier/no-market matches): Elo (start 1500, K=32) over Leaguepedia Cargo API ScoreboardGames results, last 180 days; P=1/(1+10−Δ/400), shrunk toward 50% by games played. Community/results source: Leaguepedia; cross-check stats at gol.gg.
  5. ⚠️ Unresolved: no market + no team history → 50/50, nominal pick, flagged on the Unresolved and Flagged pages with limitations.

Updating

GitHub Actions workflow update-picks.yml runs every 6 hours (within the requested 4–8h), re-scrapes, re-prices, commits data/picks.json and redeploys this site. Every row links its evidence source and the official Hotspawn match page where available; unconfirmed values are left as 50/50 and flagged, never invented.

Established LoL betting sources consulted

  • Pinnacle (sharp benchmark; public API closed to general public since 2025-07-23 — github.com/pinnacleapi/pinnacleapi-documentation), reached via OddsPapi when keyed.
  • Polymarket (public Gamma API, above).
  • OddsPapi bookmaker network (350+ books, LoL sportId 18).

Not betting advice. Pick'em is free-to-play on Hotspawn.
