What each flag means

NO_EXTERNAL_MARKET
No bookmaker or prediction-market line was found for this fixture, so the pick comes from our own model (or is unresolved).
NO_TEAM_HISTORY
Neither team has recorded games in the last 365 days; the row is an explicit 50/50 placeholder.
ONE_TEAM_NO_HISTORY
One side has no usable history, so the model substitutes the competition median or tier prior and shrinks toward 50/50.
THIN_HISTORY
Fewer than five recorded games in 365 days for at least one team — the rating is unstable.
MODEL_ELO_THIN
The Elo row is published but one side has fewer than eight games; confidence is capped at Low.
CROSS_LEAGUE_MODEL
The two teams' recent competitions differ, so absolute league strength matters more than usual. Confidence is capped and any model–market gap is treated as indicative.
MODEL_DISAGREES_WITH_MARKET
The model differs from the external consensus by 8 points or more in the same competition. The published pick follows the market; the gap is shown.
MARKET_DISAGREEMENT
Sources disagree with each other by more than 10 probability points.
START_TIME_DISAGREES_WITH_BOOKS
A bookmaker's start time differs from Hotspawn's by more than 90 minutes. Hotspawn's timestamp is used for display; the delta is recorded on the match page.
START_TIME_MISMATCH
Hotspawn and Leaguepedia disagree on the start time by more than 30 minutes.
NO_HOTSPAWN_MATCH_PAGE
Hotspawn lists the fixture but has not published a match page, so the row links the lobby instead of a dead match URL.
TIER_UNVERIFIED
Hotspawn has not assigned a tier badge yet (the fixture is still waiting for information).
NO_VERIFIED_SIGNAL
No external market and no model output — unresolved placeholder.
