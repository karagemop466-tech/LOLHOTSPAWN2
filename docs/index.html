🧮 Matches without a featured betting line — how each pick is made

The featured picks are priced from de-vigged sportsbook and prediction-market lines. Every other match on Hotspawn's list still gets a pick, from our own line: chronological, competition-anchored Elo over Leaguepedia's recorded series, blended with the current split standings when a side has too little history. Where the evidence is thin the row says so and is capped at Low confidence — and if no evidence exists at all the row is published as an explicit 50/50 on Unresolved & limitations, never as an edge.
