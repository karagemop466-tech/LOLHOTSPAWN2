How these picks are made — and what is never used

We mirror every upcoming scheduled LoL fixture on Hotspawn's Pick'em lobby and originate an independent probability for each one: 💰 de-vigged sportsbook & prediction-market lines first, otherwise 🧮 our own Elo model on recorded results and split standings. Hotspawn crowd percentages are context only — never an input to any probability.

Sources are requested once per refresh and the result is published whether it worked or not (source-by-source checks →); the method and its out-of-sample error are on Methodology →.
