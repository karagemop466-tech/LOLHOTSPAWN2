Executive summary

Every LoL match on Hotspawn's Pick'em list — with a pick and a win probability.

This site mirrors the League of Legends fixtures on Hotspawn's Pick'em lobby and prices every one of them: matches covered by established bookmakers use the external market consensus, everything else is priced by our own Elo model built from recorded match results. Hotspawn's crowd percentages are shown as context only and are never an input to a probability.
